A simple and user-friendly calculator application developed using Python and Tkinter. This project performs basic mathematical operations such as addition, subtraction, multiplication, division, and percentage calculations.
The project is organized into three separate Python files:
- **main.py:** Runs the calculator application.
- **ui.py:** Handles the graphical user interface (GUI).
- **calculator_logic.py:** Performs mathematical calculations.
**Technologies Used:** Python, Tkinter, AST.
Developed as part of the CODSOFT Python Programming Internship.
