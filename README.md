# Calculator – CODSOFT Internship Task 2

## About the Project
This is a simple and interactive calculator application developed using Python and Tkinter as part of my CODSOFT Python Programming Internship.
The application provides a clean graphical interface to perform basic mathematical calculations.
## Features
- Addition, subtraction, multiplication and division
- Percentage calculation
- Clear and delete functions
- Keyboard support
- Error handling for invalid calculations
- User-friendly graphical interface
## Technologies Used
- Python
- Tkinter
- Abstract Syntax Trees (AST)
## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:
```bash
python calculator.py
```
